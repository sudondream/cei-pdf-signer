Installation

Instalare

1

Install IDPlugManager

Instaleaza IDPlugManager

Download and install from HUB MAI ROMANIA

Descarca si instaleaza de pe HUB MAI ROMANIA

2

Download CEI PDF Signer

Descarca CEI PDF Signer

Get the latest release from GitHub

Descarca ultima versiune de pe GitHub

CEI-PDF-Signer-v0.15-beta-macOS.zip
3

Move to Applications

Muta in Applications

Extract and drag CEI PDF Signer.app to your Applications folder

Extrage si trage CEI PDF Signer.app in folderul Applications

4

Open it

Deschide-o

Insert your card, double-click the app, and sign. It is notarized by Apple, so there is no warning and no security setting to change.

Introdu cardul, dublu-click pe aplicatie si semneaza. Este notarizata de Apple, deci nu apare niciun avertisment si nu ai nicio setare de securitate de schimbat.

Signed and verifiable

Semnata si verificabila

This application is signed with an Apple developer certificate and notarized by Apple, so macOS opens it without any warning. You do not need to change any security setting.

Aplicatia este semnata cu un certificat de dezvoltator Apple si notarizata de Apple, asa ca macOS o deschide fara niciun avertisment. Nu trebuie sa modifici nicio setare de securitate.

The entire source code is public, and every release is built from it. Your PIN and your certificate never leave your computer: the document is signed locally, by the card itself.

Codul sursa este public in intregime, iar fiecare versiune este construita din el. PIN-ul si certificatul tau nu parasesc niciodata calculatorul: documentul este semnat local, chiar de card.

Checking the download yourself (optional)

Verificarea descarcarii (optional)

Every release publishes a SHA256SUMS.txt next to the archive. Download it, put it beside the ZIP, and run this in Terminal — OK means the file is byte-for-byte the one that was published.

Fiecare versiune publica un fisier SHA256SUMS.txt langa arhiva. Descarca-l, pune-l langa ZIP si ruleaza comanda de mai jos in Terminal — OK inseamna ca fisierul este identic cu cel publicat.

cd ~/Downloads && shasum -a 256 -c SHA256SUMS.txt
